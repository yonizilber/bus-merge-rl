# בדיקות

בפרויקט הזה הבדיקות הן חלק מהתוצאה. מספר ראוי לפרסום רק אם אותו קוד שהאפליקציה מריצה הפיק אותו, ואם בדיקה היתה
תופסת אותו אילו השתבש.

{{test_totals}} [דוח הבדיקות](TEST_REPORT.html) מפרט כל מקרה בדיקה עם התוצאה שלו, מהרצה אמיתית אחת.

## עקרונות

- **רתמה אחת לכל מספר.** האפליקציה, חבילת הבדיקות, סקריפט האימות ו[[nightly|שערי הלילה]] מריצים כולם אותו קוד אפיזודה
  ושופטים אותו באותה דרך. הבדל בין בדיקה לאפליקציה נחשב באג, לא "בעיה ידועה".
- **אין תיקונים נסתרים.** מהירות ומיקום נגזרים רק מתאוצה. כל הרצה נבדקת לרגעים שאי אפשר שיקרו במציאות
  ([[invariants|בדיקות פיזיקה]]) במקום שיחתכו אותם. מודל שנכשל בגלוי עדיף על מודל שממציא.
- **כל שומר יכול להיכשל.** לצד כל בדיקה יש הוכחה שהיא תופסת את הבעיה שבשבילה נכתבה: בדיקת ההיגוי מורצת מול הבקר
  הישן שחרג מהיעד, בדיקת העצירה באמצע הדרך מול v11, בדיקת ההתאמה מול סטייה שהוזרקה, וסריקת בסיס האמת היחיד מול עותק
  שנשתל.
- **מגבלות ידועות נשארות גלויות.** בדיקת [[strict_xfail|xfail קשיח]] שומרת את ההנחה הכנה בחבילה, והופכת לאדומה ביום
  שההתנהגות משתנה.
- **כל מספר מתפרסם נוצר אוטומטית** ממדידות שמורות לכל seed; בדיקה נכשלת אם עמוד שונה מהן.

## שכבות

| שכבה | מתי | מה היא מריצה |
|---|---|---|
| CI | בכל push | בודק קוד ואת כל החבילה, בכשתי דקות |
| [[nightly|שערי הלילה]] | כל לילה ב-GitHub | סוכן ברירת המחדל על seeds שלא משמשים בשום מקום אחר: 200 בהגדרות האפליקציה, ואז 50 בכל אחת מארבע עוצמות תנועה |
| [[acceptance|שער הקבלה]] | לפני בחירת מוח | 100 אפיזודות ברעש 0 ו-0.15, עם גבולות הזמן |
| אימות | כשמפרסמים תוצאה | 1,000 אפיזודות על seeds 2000-2999, עם [[wilson|רווחי ביטחון]] |
| באפליקציה | ידנית | הבאנר מראה את התוצאה, את פירוט זמן ההשתלבות ואת בדיקות הפיזיקה של כל הרצה |

טווחי ה-seeds אף פעם לא חופפים: 1000-1099 לבחירה בין מועמדים, 2000-2999 למספרים המתפרסמים, 3000-3249 לשערי
הלילה.

## מגבלות ידועות כבדיקות

יש 13 מקרי [[strict_xfail|xfail קשיח]] שמתעדים מגבלה של המנוע או של הסוכן, ועוד 9 שעברו בירושה מהפרויקט המקורי,
נכתבו מול ממשק ישן ונשמרו עד שייכתבו מחדש. כל אחד מ-13 מצטט את הפריט שלו ברשימה בעמוד [המגבלות](LIMITATIONS.md).

| מגבלה | עוקבת אחריה | מזהה |
|---|---|---|
| הסוכן לפעמים יוצא כשמכונית נמצאת לצד האוטובוס (כ-2% מההרצות) | `test_brain_behaviour.py` | O2 |
| מהקצה הרחוק של המפרץ הסוכן מנווט החוצה לאט מדי וחותך את שפת היציאה (כ-9%) | `test_brain_behaviour.py` (2 מיקומים) | O12 |
| מהירות האוטובוס העומד מוצבת ל-0; תרחיש אחד מאפס את תנוחת האוטובוס | `test_no_state_assignment.py` | O5, O7 |
| **אין מסה לרכב:** אוטובוס בולם חזק כמו מכונית קומפקטית | `test_physics_limits.py` | O17 |
| **אין השהיית הפעלה לבלמים:** jerk של עד כ-107 מ'/שנ'³ | `test_physics_limits.py` | O18 |
| חוק המהירות הבטוחה יכול לחדור עד 0.55 מ' אל תוך המרווח המינימלי של 2 מ', אף פעם לא עד מגע | `test_safe_speed_properties.py` | O19 |
| מחולל המכוניות מאבד הגעות: כ-71% מהזרימה המבוקשת מסופקת בברירת המחדל | `test_traffic_density.py` (4 עוצמות) | O20 |
| **חוק ההיגוי של המכוניות חורג מהיעד:** סטייה של 0.5 מ' חורגת ב-100% בערך ולא מתייצבת | `test_car_steering_controller.py` | O21 |
| **פונקציות ה-IDM משנות את מצב הרכב:** שאילתה זהה שנייה מקבלת תשובה אחרת | `test_idm_query_side_effects.py` | O22 |

לכל אחת מאלה יש, מלבד ה-xfail, בדיקה שעוברת ומתעדת את ההתנהגות של היום (כך שסיבת הכישלון ידועה), ו-O21 מראה גם שהדרישה ניתנת להשגה: ה-pure
pursuit של האוטובוס עומד בה על אותו צעד.

כשמגבלה היא רשימה (ההשמות של מצב מחוץ לפיזיקה), בדיקה נלווית שעוברת מקבעת את הרשימה בדיוק, כך שמקרה חדש מפיל את
הבנייה.

## בדיקות ככלי גילוי

כתיבת הבדיקות מצאה בעיות אמיתיות, שכולן תוקנו או תועדו:
- **O16:** היגוי הכניסה למפרץ לא יציב לקפיצת יעד פתאומית במהירות.
- **O19:** חוק המהירות הבטוחה יכול לחדור אל המרווח המינימלי שלו. `hypothesis` מצא את המקרה הקטן ביותר.
- **O20:** מחולל המכוניות מאבד הגעות, וזה הסביר למה תוצאות מבחן העומס יצאו שטוחות.
- **H15:** האפליקציה לא הציגה תוצאה כשהאוטובוס יצא מהכביש.
- **P17 ו-P18:** הטיה במאגר של PPO ו-rollback שקט, ששניהם חסמו אימון מחדש.

מעבר ידני על האפליקציה מצא אחר כך עוד ארבעה (H17-H19 ובעיית פריסה). ראו את [היסטוריית הבעיות](HISTORY.md).

## הרצת הבדיקות

```bash
pip install -e ".[dev]"
pytest -p no:cacheprovider -q          # חבילת ה-CI
pytest --nightly -m nightly            # שערי הלילה
python scripts/build_test_report.py    # מריץ הכול וכותב את דוח הבדיקות
```
