# הכלי: מפרץ או נתיב, בתנאים שלכם

ה[תוצאות](RESULTS.md) קובעות כמה ערכים כדי לספר סיפור אחד. הכלי לא קובע אף אחד: בחרו את התנועה, את מספר האנשים במכונית
ובאוטובוס, ואת זמן העצירה בנתיב ובמפרץ (בנפרד, זהה, או זהה בתוספת עונש על העצירה הפחות מדויקת במפרץ), והוא עונה מאותן
19,500 הרצות שמורות, עם רווח סמך של 95%. ערכי ההתחלה שלו הם רק נקודת פתיחה; ההנחות שמאחוריהם, עם המקורות, נמצאות
בתחתית הכלי ובעמוד [נתוני השטח](FIELD_DATA.md).

> **הכלי האינטראקטיבי** הוא עמוד HTML: הורידו את [`stop_design_explorer.he.html`](../../../tools/stop_design_explorer.he.html) ופתחו אותו בדפדפן, או עיינו באתר ה-HTML.
