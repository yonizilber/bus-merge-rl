## התחלה מהירה

```bash
git clone https://github.com/yonizilber/bus-merge-rl.git && cd bus-merge-rl
pip install -e ".[dev]"
streamlit run streamlit_app.py
```

לוחצים על **Run Simulation**. סימון **Fixed random seed** מאפשר להריץ מחדש כל seed שמוזכר בעמודים האלה.

איך לקרוא את הטבלה:

## הסיפור בפסקה אחת

הסוכן הראשון השתלב ב-**97.9%** מההרצות שלא נראו. אחרי שכל תיקון נסתר הוסר מהסימולציה, אותן הרצות הראו את
האוטובוס **חוצה את קו האמצע ב-100% מהן**: הסוכן אף פעם לא ביקש לצאת מהמפרץ עד הסוף. הוא ביקש לצאת חצי דרך, ונתן
לבקר היגוי שעושה [[overshoot|חריגה מהיעד]] לשאת אותו אל תוך הנתיב. זה היה ניצול התגמול
שמסתמך על פגם ב-[[plant|המערכת שהוא שולט בה]]. אחרי שהבקר תוקן, אותו סוכן השתלב ב-**0%** מההרצות. כדי
להחזיר סוכן עובד היה צריך לתקן את תנוחות ההתחלה של האימון, הטיה במאגר של PPO, ו[[rollback|כלל rollback]] שאיפס
בשקט כל ניסיון. קראו את [חקר המקרה](CASE_STUDY.md), ואת [היסטוריית הבעיות](HISTORY.md) המלאה יותר, עם המקרים
האחרים שעיצבו את הפרויקט.

## איך זה עובד, בקצרה

המערכת בנויה מארבעה חלקים. העבירו עכבר על מונח לקבלת הסבר בשורה אחת, ולחצו עליו ואז על *הרחב* כדי לראות את המשוואות ואת האופן
המדויק שבו הפרויקט הזה מממש אותן.

- **התנועה.** כל מכונית היא נהג [[idm|IDM]] עם פרמטרים משלו (חמש מחלקות). בזמן שהאוטובוס משתלב, המכוניות משאירות לו יותר מקום
  ומפנות דרך בשילוב שמתגבר בהדרגה. [[safe_speed|חוק מהירות בטוחה]] אחד מגביל את התאוצה של כל רכב עוקב; מיקומים ומהירויות לא
  מוצבים אף פעם ישירות.
- **תנועת הרכבים.** התנועה לרוחב עוקבת אחרי [[bicycle|מודל אופניים קינמטי]], שמונחה על ידי [[pure_pursuit|pure pursuit]]. כל
  רכב מתנדנד בנתיב שלו כתהליך [[ou|אורנשטיין-אולנבק]].
- **הסוכן.** [[actor_critic|רשת actor-critic]] שאומנה ב-[[ppo|PPO]] רואה 11 מספרים ([[observation|התצפית]], ואם רוצים
  גם עם [[noise|רעש תפיסה]]) ומוציאה שניים: איפה להיות לרוחב, ובאיזו מהירות לנסוע. שתי שכבות כללים יכולות לבטל אותה:
  [[governor|ה-governor]] (כבוי כברירת מחדל) ו[[shield|שכבת הבטיחות]].
- **השיפוט.** כל הרצה נשפטת על ידי רתמה אחת, ו[[invariants|בדיקות פיזיקה]] מחפשות בה רגעים שאי אפשר שיקרו במציאות.

העמוד [איך זה עובד](HOW_IT_WORKS.md) מחבר את כל אלה: הרשימה המלאה של הקלטים של הסוכן, כל איברי התגמול שלו, ואיך נשפטת הרצה.

## בדיקות

{{test_totals}} החבילה מכסה את מגבלות הפיזיקה, את מודל ההיגוי, [[property_test|בדיקות מבוססות-תכונות]] של חוק
המהירות הבטוחה, התנהגות זהה של סביבת האימון והאפליקציה, דטרמיניזם, כל איבר בתגמול, בטיחות של לולאת האימון, הרצה של
האפליקציה בלי ממשק, והמספרים המתפרסמים. [[nightly|שערי הלילה]] מריצים את סוכן ברירת המחדל על seeds שלא משמשים בשום
מקום אחר. מגבלות ידועות נשמרות גלויות כבדיקות [[strict_xfail|xfail קשיח]]. ראו [בדיקות](TESTING.md), את
[המגבלות](LIMITATIONS.md) ואת [דוח הבדיקות](TEST_REPORT.html), שמפרט כל בדיקה עם התוצאה שלה.

## מגבלות ידועות

נמדדו, תועדו ונעקבות בבדיקות (עמוד [המגבלות](LIMITATIONS.md) מסביר כל אחת):
- **מגע עם מכונית שנוסעת לצד האוטובוס (כ-2%).** הסוכן לפעמים יוצא כשיש מכונית לצד המפרץ.
- **שפת המדרכה ביציאה (כ-9%).** מהקצה הרחוק של המפרץ, אחרי שנתן למכונית לעבור, הסוכן מנווט החוצה לאט מדי, ו[[kerb_corner|פינת
  מדרכה]] חודרת לצד האוטובוס.
- **פישוטים במודל.** אין מסה לרכבים (אוטובוס בולם חזק כמו מכונית), אין השהיה בהפעלת הבלמים, והאוטובוס מסתובב סביב
  מרכז הגוף שלו.
- **מחולל התנועה.** הגעות של מכוניות בזמן שהכניסה חסומה הולכות לאיבוד, ולכן הזרימה שמגיעה בפועל היא בערך
  λ / (1 + 1.5·λ): ההגדרה "0.4 מכוניות בשנייה" מספקת בערך 0.28.

## שחזור המספרים

```bash
python scripts/verify_brain.py --brain models/ppo_bus_brain_v13.pth --seeds 1000 --seed-start 2000 --save v13 --label v13
python scripts/publish_results.py          # יוצר מחדש את הטבלאות שלמעלה מתוך results/
pytest --nightly -m nightly                # שערי הלילה
```

v13 הוא v11 אחרי כוונון עדין של 300 epochs, כ-45 דקות על CPU.

## מבנה הפרויקט

```
busmerge/              מנוע הסימולציה, כלי רכב, גאומטריה, בדיקות פיזיקה, הערכה, תוצאות
  rl/                  סביבת האימון, סוכן PPO, תצפית, תגמול, governor ו-safety shield
  graphics/            ציור מלמעלה ו-GIF של ההשתלבות
streamlit_app.py       לוח בקרה אינטראקטיבי
models/                המוחות המצורפים (v13 ברירת מחדל; v9-v11 נשמרו בשביל חקר המקרה)
results/               המדידות המתפרסמות (שורות לכל seed + מקור)
scripts/               verify_brain, acceptance, train, publish_results, diagnostics
tests/                 חבילת pytest (CI) ושערי הלילה
```
